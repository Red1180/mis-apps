# Mis apps

Tres apps web personales, cada una en un solo archivo HTML, publicadas con GitHub Pages para usarlas en el celular.

- **Colonia**: mantenimiento del hogar estilo juego de colonias (limpieza, cocina, aseo y ejercicio).
- **Chanchito**: gastos, metas de ahorro y calculadoras.
- **Blackjack Brujo**: entrenador de conteo de cartas.

No hay servidor ni cuentas. Cada app guarda sus datos en el navegador del dispositivo (localStorage) y tiene un botón de respaldo para descargarlos.

Las apps se editan en otra carpeta y se copian aquí con un script para publicarlas.
